# 配合ラボ モフ

架空の生き物「モフ」をガチャで集め、配合して強い個体を育て、大会で殿堂入りを目指す育成ゲームです。
`index.html` をブラウザで開くだけで動きます (ビルド不要・依存ライブラリなし)。進行はブラウザの localStorage に保存されます。

## 遊び方

1. **ガチャで仲間を迎える** — 毎日チケットが1枚もらえます (最大3枚)。100コインでも引けます。ピックアップは4日ごとに切り替わります。★は来た群れの質で、個体の能力を保証するものではありません。
2. **見た目と実験で実力を推理する** — 遺伝子も本当の能力値も見えません。最初にわかるのは次の2つだけです。
   - 見た目: 体つき (強さ)、顔 (魅力)、毛ツヤ (生殖力)、筋肉、毛色。測る前から「速そう」「子だくさんそう」のような第一印象が出ます。見た目は実力とだいたい合っていますが、ずれもあります。生まれたばかりの子は、親についてわかっていることから「親から: 速そう」のように予想します。
   - 実験の印象: 「走らせる」→「速かった」、「写真審査」→「好評だった」など。何度か試すと傾向が見えてきます。
3. **研究所で見る力を磨く** — コインで道具や設備を解放すると、見える情報が増えます。

   | 研究 | わかるようになること |
   |---|---|
   | 観察眼の修行 | 見た目の印象が3段階から5段階に |
   | ストップウォッチ / 審査員の採点表 | 走りや審査の結果が点数で出る |
   | 動物病院と提携 | 健康診断で生殖力を測れる (それまでは見た目と出産記録だけ) |
   | 統計ノート | 点数の記録から推定値と誤差の幅を出す |
   | 血統書 | 祖父母までの血統と近交係数 |
   | DNA検査キット | 1匹80コインで毛色・体質の遺伝子 |
   | ゲノム解析装置 | 1匹150コインで能力の遺伝子まで全部 |
   | 交配シミュレータ | 検査済みの親どうしの子を交配前に予想 |
   | 繁殖小屋の増築 / 2棟目 | 1晩に組めるペアが2組 / 3組に |
   | 遺伝子バンク | ♂の遺伝子を保存し、旅立ったあとも父にできる |

4. **配合して強い子を作る** — 交配は夜の出来事です。昼のうちに父と母を選んで「今夜のペア」に登録しておくと、翌朝までに子が生まれ、わらのかごに子どもが入ってくる演出が出ます。登録しても行動は使わないので、実験や大会のあとでも組めます。1晩に組めるのは最初1組で、研究所の繁殖小屋で2組、3組に増やせます。必ず1匹以上生まれ、何匹生まれるかは主に母の生殖力 (父も少し) で決まります。子は2日で大人になり、体つきが見えてきます。幼体のうちも実験で「大人になったときの見込み」を測れますが、ぶれは大きめです。飼育場があふれたときは、里親に出す子を自分で選びます。ふつうに見える親どうしから、隠れていた特異体質の子が生まれることもあります。
5. **大会で殿堂入り** — モフレース (強さ)、美モフコンテスト (魅力)、品評会 (3能力の平均)。優勝でランクが上がり、3種目すべての王者で優勝すると殿堂入りです。王者を制覇した種目は防衛戦になり、防衛するたびに賞金が減ります (1000 → 500 → 333 …)。レースは実際に走る演出、コンテストと品評会は下位から順に発表し、3位までにはロゼットが出ます。

飼育場は最初12匹、1回だけ広げて最大16匹です。大人のモフは1日1回だけ、実験か大会のどちらかができます (交配は行動を使いません)。「次の日へ」で餌代 (大人3・幼体1コイン/匹) を払って翌日へ進みます。

### 年齢と別れ

- 年はゲーム内の日数で数えます (「次の日へ」を押したときだけ進む)。
- 若いうちは能力が伸び、全盛期を過ぎると強さと生殖力が衰えます (魅力は落ちにくい)。全盛期の時期は成長型 (早熟 / 普通 / 晩成) で変わります。
- 寿命は平均19日ほど (12〜28日)。長生き遺伝子で延び、生殖力の高い血統ほど少し短命です。
- 年をとると白髪が出て、寿命が近づくと「よぼよぼ」になります。そのまま数日で旅立ちます。
- 白髪が出たときと、よぼよぼになったときは、朝のまとめで知らせます。
- 衰えてきた子は自分で「送り出す」こともできます。数日後に旅先から手紙とおみやげのコインが届きます。自然に旅立った子からも、手紙だけは届きます。手紙はその子の生き方 (優勝、子ども、毛色など) にちなんだ文面になることがあります。
- 旅立った子は「思い出アルバム」に残ります。研究所の遺伝子バンクで保存した♂は、旅立ったあとも父にできます。
- 寿命の長さは `tools/balance-sim.js` のシミュレーションで決めました。平均19日だと殿堂入りまで約34日・約11世代で、1回の通しプレイで優勝経験のある子との別れが3回ほどあります。

### 特異体質

まれに、見た目でもはっきりわかる極端な個体が現れます。どちらも遺伝します。

- **めっちゃムキムキ** (超筋肉 `xx`, 潜性): 強さ +30、生殖力 −20。実在する牛の「ダブルマッスル」(ミオスタチン遺伝子の変異) がモデル。保因者 `Xx` は見た目が普通です。
- **多産体質** (`Q`, 1本 +18 / 2本 +32 生殖力): 羊のブールーラ遺伝子がモデル。♂は睾丸がめちゃくちゃデカく、♀はお腹まわりがふっくらします。

## 遺伝モデル

| 遺伝子 | 座位 | しくみ |
|---|---|---|
| 強さ | 4 | `+` の数の足し算 (量的形質) |
| 魅力 | 4 | 同上 |
| 生殖力 | 3 | 同上 |
| 筋肉 M | 1 | 顕性。強さ +15 / 生殖力 −15 (多面発現のトレードオフ)。見た目でわかる |
| 超筋肉 X | 1 | `xx` で強さ +30 / 生殖力 −20 (潜性) |
| 多産 Q | 1 | 1本で生殖力 +18、2本で +32 (強さ −8) |
| 健康 D | 1 | `dd` のみ発症し全能力ダウン (潜性)。`Dd` の保因者は見た目ではわからない |
| 色素 C・黒毛 B | 2 | `cc` は白 (エピスタシス)、`B_` 黒、`bb` 茶 |
| 斑紋 P | 1 | 不完全顕性: `PP` 大斑、`Pp` 小斑 |
| 寿命 | 3 | 足し算。1本ごとに寿命 +2日 |
| 成長型 E | 1 | `EE` 早熟 / `Ee` 普通 / `ee` 晩成 |

- 二倍体。各座位で父母から1本ずつランダムに受け継ぎます (独立の法則)。突然変異率は 0.5%。
- 能力値 = 遺伝的な値 + 育ちのぶれ (正規分布, 標準偏差 6)。見た目は能力値にさらに個体ごとのずれ (標準偏差 8) を加えたものから描かれます。
- 近交係数は血統から Malécot の近縁係数で計算します。
