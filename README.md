# 配合ラボ モフ

架空の生き物「モフ」を交配して、**強さ・魅力・生殖力**を受け継がせる遺伝子配合シミュレータです。
`index.html` をブラウザで開くだけで動きます (ビルド不要・依存ライブラリなし)。

## 2つのモード

### 飼育場で配合 (手動)
- 台帳から ♂ と ♀ を選ぶと、子の能力値の分布 (2000回の試行)、毛色・病気の確率、近交係数を予想します。
- 「交配する」で子が生まれます。受胎率は父の生殖力、産子数は母の生殖力で決まります。
- 個体記録で遺伝子型と血統 (祖父母まで) を確認できます。
- 目標: 3つの能力がすべて 80 以上の個体を育てる。
- 台帳はブラウザの localStorage に保存されます。

### 集団で進化 (自動)
1世代ごとに次の順で進みます。

1. **生存** (自然選択): 強さが高いほど生き残りやすい。魅力が高いほど天敵に見つかりやすい (派手さの代償)。
2. **配偶者選択** (性選択): ♀は魅力の高い♂を選びやすい。
3. **繁殖**: 生殖力が高いほど子が多い。子の数は環境収容力 K で頭打ち。

平均能力値・遺伝子頻度・個体数の推移をグラフで追えます。集団の個体をタップすると飼育場へ迎えられます。

## 遺伝モデル

| 遺伝子 | 座位 | しくみ |
|---|---|---|
| 強さ | 4 | `+` の数の足し算 (量的形質) |
| 魅力 | 4 | 同上 |
| 生殖力 | 3 | 同上 |
| 筋肉 M | 1 | 顕性。強さ +15 / 生殖力 −15 (多面発現のトレードオフ) |
| 健康 D | 1 | `dd` のみ発症し全能力ダウン (潜性)。近親交配で出やすい |
| 色素 C・黒毛 B | 2 | `cc` は白 (エピスタシス)、`B_` 黒、`bb` 茶 |
| 斑紋 P | 1 | 不完全顕性: `PP` 大斑、`Pp` 小斑 |

- 二倍体。各座位で父母から1本ずつランダムに受け継ぎます (独立の法則)。
- 突然変異率 μ で遺伝子が反転します。
- 能力値 = 遺伝的な値 + 環境ゆらぎ (正規分布, 標準偏差 σ)。
- 近交係数は血統から Malécot の近縁係数で計算します。
