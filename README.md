# 配合ラボ モフ

架空の生き物「モフ」をガチャで集め、配合して強い個体を育て、大会で殿堂入りを目指す育成ゲームです。
`index.html` をブラウザで開くだけで動きます (ビルド不要・依存ライブラリなし)。進行はブラウザの localStorage に保存されます。

## 遊び方

1. **ガチャで仲間を迎える** — 毎日チケットが1枚もらえます (最大3枚)。100コインでも引けます。ピックアップは4日ごとに切り替わります。★は来た群れの質で、個体の能力を保証するものではありません。
2. **実験と見た目で能力を見きわめる** — 遺伝子も本当の能力値も見えません。
   - 走らせる → 強さ / 写真審査 → 魅力 / 健康診断 (40コイン) → 生殖力。どれも誤差つきで、測るほど推定の幅が狭くなります。
   - 見た目にもヒントがあります: 体の太さ (強さ)、目の大きさとほっぺ (魅力)、毛ツヤ (生殖力)、筋肉 (M 遺伝子)、毛色。
   - 遺伝子検査 (150コイン) で遺伝子型がすべてわかります。両親とも検査済みなら、交配前に子の予想が見られます。
3. **配合して強い子を作る** — 受胎率は父の、産子数は母の生殖力しだい。子は2日で大人になります。近親交配は隠れた病気遺伝子をそろえやすくします。
4. **大会で勝ち上がり殿堂入り** — モフレース (強さ)、美モフコンテスト (魅力)、品評会 (3能力の平均) の3種目。優勝でランクが上がり (初級→中級→上級→王者)、3種目すべての王者で優勝すると殿堂入りです。

1日の行動: 大人のモフは1日1回だけ、実験・交配・大会のどれかができます。「1日を終える」で餌代 (大人5・幼体2コイン/匹) を払って翌日へ進みます。

## 遺伝モデル

| 遺伝子 | 座位 | しくみ |
|---|---|---|
| 強さ | 4 | `+` の数の足し算 (量的形質) |
| 魅力 | 4 | 同上 |
| 生殖力 | 3 | 同上 |
| 筋肉 M | 1 | 顕性。強さ +15 / 生殖力 −15 (多面発現のトレードオフ)。見た目でわかる |
| 健康 D | 1 | `dd` のみ発症し全能力ダウン (潜性)。`Dd` の保因者は見た目ではわからない |
| 色素 C・黒毛 B | 2 | `cc` は白 (エピスタシス)、`B_` 黒、`bb` 茶 |
| 斑紋 P | 1 | 不完全顕性: `PP` 大斑、`Pp` 小斑 |

- 二倍体。各座位で父母から1本ずつランダムに受け継ぎます (独立の法則)。突然変異率は 0.5%。
- 能力値 = 遺伝的な値 + 育ちのぶれ (正規分布, 標準偏差 6)。
- 近交係数は血統から Malécot の近縁係数で計算します。
